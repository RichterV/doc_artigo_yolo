# Extras

The repository contains scripts that the paper's analysis **does not** use. They are documented here briefly, so you know what they are and can skip them safely.

| Extra | Folder | Status in the paper |
|---|---|---|
| [RGB vegetation indices](rgb-indices.md) | `rgb_drone` (`ivs`, `rgb_ivs` feature sets) | not reported |
| [Wall-to-wall mapping](mapping.md) | `rgb_drone`, `rgb_micasense` (`4_pos_processamento_shps.py`) | not reported |
| [Explainability (XAI)](xai.md) | `rgb_drone` (`7xai_rgb_integrated.py`, `8_estatistica_xai_rgb.py`) | not reported |
